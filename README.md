# sadinews
A website repo for sadinews 
redeploy

Authors and administrators can import article cover photos while writing or editing
an article. Under **Cover photo**, paste a direct HTTPS image URL into **Or import a
cover photo from a link**, then save the draft, submit it for review, or publish it.
The site downloads and stores its own copy, rather than relying on the original
host to keep serving the image. PNG, JPG, GIF and WebP images up to 5 MB are
supported. Image links must be public and open the image itself, not a web page;
links requiring login are not supported. Choose either a file or a link. Leaving
both empty preserves the article's existing cover.
